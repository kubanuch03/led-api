# led-api — вывод карточки парковки на LED-экран

HTTP-сервис на FastAPI. Бэкенд парковки по событию оплаты шлёт один POST — на экране
появляется карточка: QR сверху, снизу госномер, время, сколько простояла машина и сумма.

Заменяет собой `tools/hd9527/` (россыпь `.cmd`, PowerShell-рендер и два параллельных
клиента на Node и Python). Здесь один процесс, чистый Python, без PowerShell и Node.

## ⚠️ Два условия, без которых табло молчит

Оба выяснены замерами на живой панели 21.09.2026. Сервис при их нарушении выглядит
полностью исправным — отвечает `200 OK`, — а экран не меняется. Именно так объект
простоял с чёрными табло.

**1. Запрос к панели обязан идти из сети объекта.** Через внешний туннель кадр
записывается и все 18 кадров получают ack, но панель программу **не применяет** и
держит старое изображение. Поэтому led-api поднят контейнерами на самом сервере
объекта (`led_api_75` → `10.30.205.75`, `led_api_76` → `10.30.205.76`), а не
дёргает панель снаружи.

HTTP-вход при этом снаружи доступен и это нормально: по туннелю идёт маленький
JSON, а тяжёлую заливку по 9527 делает уже сервис из локальной сети.

**2. Имена файлов кадра и программы обязаны быть уникальными.** Попытка ограничить
рост карты постоянными именами («слотами») ломает применение: карта не заменяет
содержимое файла по существующему имени, md5 в программе перестаёт сходиться, и
карта программу отвергает — в активной программе остаётся один файл вместо двух.
Подробности и A/B-замер — в комментарии к `SLOTS` в `app/panel.py` и в тесте
REG-20. Плата за уникальные имена — накопление файлов на карте; решать это надо
не именами.

## Быстрый старт

```bash
cp .env.example .env          # при необходимости поправить адрес панели и токен
docker compose up -d --build
curl localhost:8840/health
```

Документация API откроется сама: **http://localhost:8840/docs**

## Отправить карточку

```bash
curl -X POST localhost:8840/card -H 'Content-Type: application/json' -d '{
  "qr": "https://tinyurl.com/2xmbn6a3",
  "plate": "01KG777AAA",
  "amount": "250 KGS",
  "time": "20:30",
  "dur": "1ч40м"
}'
```

```json
{"ok": true, "verified": true, "md5": "d98a96…",
 "render": {"qr_version": 2, "qr_modules": 25, "module_px": 5, "qr_side_px": 125}}
```

`verified: true` означает, что карта **действительно записала** файл, а не просто
подтвердила кадры (см. «Честный ответ» ниже). Вся операция занимает ~4 с.

## Эндпоинты

| Метод | Путь | Зачем |
|---|---|---|
| GET | `/health` | жив ли сервис и панель: ID, IP, MAC, размер, включён ли экран, играет ли программа |
| GET | `/screen` | что реально лежит на карте (md5 активной программы) и наше ли это |
| POST | `/card` | **основной вход**: JSON со ссылкой QR и полями карточки |
| POST | `/card/form` | то же формой; можно прислать готовую картинку QR файлом `qr_image` |
| POST | `/preview` | нарисовать карточку и вернуть PNG, **ничего не отправляя** (`?scale=4` — крупнее) |
| POST | `/image` | показать готовый PNG как есть |
| POST | `/blank` | погасить экран |

Поля `/card`: `qr` (обязательное), `plate`, `amount`, `time` (пусто — текущее),
`dur`, `qr_pct`, `pos` (`bottom`/`top`/`none`), `white`, `ecc`, `verify`.

## Читаемость QR — главное ограничение

Экран 160×160 светодиодов. **Модуль QR должен быть не меньше 4 px**, иначе с улицы
камера телефона его не разделит: на солнце экспозиция зажимается, в тени свечение
белых модулей растекается и съедает чёрные. Отсюда: на экран влезает только
**короткая ссылка (~28 символов)**.

| Ссылка | Версия QR | Модулей | px/модуль | С улицы |
|---|---|---|---|---|
| `https://pay.kg/p/A1B2C3` (23 симв.) | 2 | 25 | 5 | да |
| платёжный payload Bakai (139 симв.) | 7 | 45 | 3 | **нет** |

Длинные платёжные ссылки укорачивайте редиректом на своём домене. Сервис сам считает
геометрию и возвращает `module_px`, а если модуль меньше 4 px — кладёт в ответ `warning`.

Передавайте **ссылку текстом** в поле `qr`: тогда модули ложатся точно в пиксели панели.
Готовая картинка (`qr_image`) масштабируется и на улице читается заметно хуже — сервис
об этом предупреждает в ответе.

## Что сервис делает такого, чего не делали скрипты

**Честный ответ об успехе.** В протоколе 9527 `ack` значит «кадр получен», а не «файл
записан»: карта умеет подтверждать все 18 кадров и не сохранить ничего (так и было
2026-09-07 — зависшая карта неделю показывала старое, а скрипты рапортовали об успехе).
Поэтому после отправки сервис переоткрывает сессию и сверяет md5 в списке активной
программы. `verified: false` — повод перезагрузить панель по питанию.

**Поворот кадра на 180°.** Панель выводит картинку перевёрнутой: HDPlayer поворачивает
её у себя, а `Rotation=2` в программе пишет лишь меткой. Скрипты копировали метку, но не
поворот — и текст выходил вверх ногами. Поворот встроен в отправщик, поэтому действует
на любой путь, включая готовую картинку от бэкенда. Отключается `HD_ROT180=0`.

**`/preview`.** Вёрстку видно, не занимая экран и не выходя на объект.

## Настройки (env)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `HD_HOST` | `10.30.205.20` | адрес панели |
| `HD_DEVICE_ID` | `C16L-B25-07457` | ID карты (идёт в программу) |
| `HD_WIDTH` / `HD_HEIGHT` | `160` | размер экрана |
| `HD_ROT180` | `1` | поворот кадра под установку панели |
| `HD_WHITE` | `255` | яркость светлых модулей QR (170–200 в тени и ночью) |
| `HD_TZ_OFFSET` | `6` | часовой пояс для времени по умолчанию |
| `API_TOKEN` | пусто | если задан — нужен `Authorization: Bearer <token>` |
| `HD_BUSY_WAIT` | `20` | сколько ждать освобождения панели до ответа `429` |

Панель принимает **одно** соединение на порт 9527, поэтому команды сериализованы:
пока идёт отправка, параллельный запрос ждёт и по истечении `HD_BUSY_WAIT` получает `429`.
По той же причине на время работы сервиса HDPlayer должен быть закрыт.

## Устройство

```
app/panel.py    протокол 9527: рукопожатие, файлы, программа, поворот PNG, UDP-статус
app/render.py   рендер карточки под пиксельную сетку (Pillow + qrcode)
app/main.py     FastAPI: эндпоинты, очередь к панели, токен
app/config.py   настройки из окружения
```

`panel.py` не тянет зависимостей — только сокеты и zlib, поэтому годится и как библиотека:

```python
from app.panel import Panel, udp_status
print(udp_status("10.30.205.20"))
Panel("10.30.205.20").send_png(open("card.png", "rb").read())
```

Подробности железа и протокола — `../LED-DIAGNOSTICS.md` и `../tools/hd9527/LED-SCREEN.md`.
